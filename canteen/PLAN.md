# 期末大作业实施计划（初稿）

> 项目：校园食堂信息系统（品味堂 · 余味堂 · 知味堂）
> 日期：2026-09-19
> 说明：本文件为初稿，随项目推进滚动修订。

## 一、项目简介

面向在校师生的食堂人流信息展示系统：实时查看三座食堂的当前人数与容量，比较当日分时段人流量，查看各食堂客流最高的门店，并通过三维场景直观感受各食堂拥挤程度。技术路线沿用课堂所学：Bootstrap 布局 + jQuery 交互 + ECharts 图表 + Three.js 三维 + 原生 JS 数据处理。
