# 校园食堂信息系统

课堂综合案例：展示校园三座食堂（**品味堂 · 余味堂 · 知味堂**）的实时人数、当日人流量与门店客流排行，并提供三维人流导览。

- **总览**：三食堂实时人数 / 总容量 / 占用率进度条 / 拥挤级别徽标，Hero 区汇总全校区数据，每 5 秒模拟刷新（可暂停）
- **当日人流**：ECharts 分组柱状图，三食堂 06:00–20:00 分时段客流量对比
- **门店排行**：各食堂客流 Top1 门店卡片（含第 2–4 名列表）+ 各食堂 Top3 门店横向条形图
- **三维导览**：独立子页，Three.js 食堂场景——楼顶状态灯与楼体颜色随占用率变化（空闲绿 / 适中黄 / 拥挤红），门前排队人数随实时人数增减，名牌实时显示当前人数

模块间衔接：三维页与首页读取同一份 `data/data.json`，拥挤度阈值（<60% 空闲、60%–85% 适中、>85% 拥挤）在页面卡片与三维场景中保持一致。

## 运行方法

**推荐：本地 HTTP 服务器**（图表与三维页需要 `fetch` 读取本地 JSON）

在仓库根目录（本文件的上两级）执行：

```bash
python -m http.server 8123
```

然后浏览器打开：

- 首页：<http://localhost:8123/canteen/index.html>
- 三维导览：<http://localhost:8123/canteen/three-d/scene.html>

也可以**直接双击 `index.html`** 以 `file://` 方式打开：浏览器禁止读取本地 JSON，页面自动改用 `js/app.js` 内置的同款示例数据，总览与图表仍可正常使用（数据来源会提示为"内置示例数据"）；三维页则提示数据加载失败但场景仍可浏览。

> 注意：所有第三方库走 CDN，首次打开需要联网；断网时页面顶部会出现红色提示条。

## 目录说明

```text
canteen/
├── index.html              # 统一入口（总览 / 当日人流 / 门店排行三个锚点区块）
├── css/
│   └── style.css           # 自定义样式，在 Bootstrap CSS 之后引入
├── js/
│   └── app.js              # 交互逻辑，按 data / render / bindEvents 分层
├── data/
│   └── data.json           # 三食堂容量、实时人数、分时段人流、门店客流
├── three-d/
│   └── scene.html          # 三维人流导览独立子页（Three.js）
├── PLAN.md                 # 期末大作业实施计划初稿
└── README.md               # 本文件
```

三维库只在 `three-d/scene.html` 加载，不拖慢首页。

## 数据和资源来源

- `data/data.json` 为**课堂演示模拟数据**，非真实食堂监测系统；字段：食堂名称、总容量、实时人数、分时段人流（人次/小时）、门店当日客流（人次）。
- 实时人数的"每 5 秒刷新"为**前端模拟波动**（±3%），用于演示实时效果，非真实数据接入。
- 第三方库全部来自 jsDelivr 公共 CDN（版本见上表）；三维场景中的楼体立面、名牌均为 Three.js 程序化生成（Canvas 贴图 / 精灵），未使用外部图片素材。
