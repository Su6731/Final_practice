# 校园公共信息与数据展示中心

期末综合作品（个人独立完成）。围绕校园公共服务主题，把课堂上的**运动场馆、食堂、自习室**三个练习整合为一个统一入口的响应式前端应用：一个信息首页 + 综合查询、数据中心两个功能页面 + 一个三维校园展示区。

## 一、作业要求对照

| 作业要求 | 实现位置 |
| --- | --- |
| 信息首页 + 至少 2 个功能页面，手机 / 桌面响应式 | 首页 `index.html`、功能页 `query.html`（综合查询）、`stats.html`（数据中心）、三维页 `three-d/scene.html`；375 / 768 / 1200 三档断点，手机汉堡导航、卡片单列，桌面多列 |
| 交互查询模块（筛选 / 搜索 / 添加 / 修改任选） | `query.html`：三类服务选项卡切换 + 名称关键词搜索 + 各业态条件筛选（场馆：室内/室外、拥挤状态；食堂：拥挤状态；自习室：楼层、开放状态），输入即时生效、可一键重置 |
| 基于 JSON 的数据加载 | 全部页面 `fetch('data/data.json')`（公共层 `js/common.js`）；`file://` 双击直开时自动回退内置同款数据，功能不受影响 |
| 至少两类有效图表 | `stats.html` 共 **7 张、4 类** ECharts 图表：柱状图（场馆人流排行 / 食堂分时客流 / 自习室使用量）、折线图（场馆分时段趋势）、饼图（人流占比 / 自习室开放状态环形图）、横向条形图（食堂 Top3 门店） |
| 一个与主题相关的三维展示区域 | `three-d/scene.html`：Three.js 校园三区一体场景——西区操场/篮球馆/羽毛球馆/游泳馆/排球场/网球场，东南三座食堂（门前排队人数随占用率变化），东北图书馆/自习中心（灯色随开放比例变化）；可旋转、缩放、平移、自动环绕 |
| 完整的错误提示和运行说明 | 每页顶部断网 / CDN 失败红色提示条；空数据占位提示；三维页加载失败与 8 秒超时兜底；本文件即完整运行说明 |
| 至少使用 jQuery 或 Bootstrap 之一 | jQuery 3.7.1 + Bootstrap 5.3.3（均使用，CDN 锁版本） |
| 至少使用 Three.js 或 A-Frame 之一 | Three.js 0.160.0（ES Module + importmap，CDN 锁版本） |

## 二、运行方法

### 方式一：一键启动（推荐）

双击根目录的 `启动服务器.bat`，自动在本目录启动本地服务器（端口 8123）并打开首页；关闭命令行窗口即停止服务。此方式读取真实的 `data/data.json`，修改数据后刷新即生效。

等价手动命令（在本目录执行）：

```bash
python -m http.server 8123
```

然后访问：

- 首页：<http://localhost:8123/index.html>
- 综合查询：<http://localhost:8123/query.html>
- 数据中心：<http://localhost:8123/stats.html>
- 三维校园：<http://localhost:8123/three-d/scene.html>

### 方式二：直接双击 index.html（file://）

不启动服务器也能完整使用：浏览器禁止 `file://` 页面读取本地 JSON，页面会自动切换到 `js/common.js` 与三维页内置的同款示例数据（Console 仅有 warn 提示，无红色报错）。限制：修改 `data/data.json` 不生效，需同步修改 `js/common.js` 中的 `FALLBACK`。

> 第三方库走 jsDelivr CDN，首次打开需要联网；断网时页面顶部出现红色提示条，三维页加载位显示“三维资源加载失败”。

## 四、数据说明

- `data/data.json` 为**课堂演示模拟数据**，非真实监测系统，包含：
  - `venues`：6 处运动场馆的类型、容量、当前人数快照、开放时间、昨日 06:00–21:00 分时段人流；
  - `canteens`：3 座食堂的容量、当前人数快照、昨日 06:00–20:00 分时段客流、各门店昨日客流；
  - `rooms`：10 间自习室的楼层、座位数、开放状态、开放时间、本周使用量（人次）。
- “昨日总人流量”为各时段人次之和；“高峰时段”由公共层 `statsOf` 计算（人数相同时取最早时段）。
- 拥挤度阈值在卡片、图表页与三维场景中保持一致：占用率 **< 60% 空闲（绿）· 60%–85% 适中（黄）· > 85% 拥挤（红）**；自习楼按开放房间比例着色：**≥ 80% 充足 · ≥ 50% 适中 · 其余紧张**。
- 第三方库来自 jsDelivr CDN（jQuery 3.7.1、Bootstrap 5.3.3、Bootstrap Icons 1.11.3、ECharts 5.5.1、Three.js 0.160.0）；三维建筑立面、名牌均为程序化生成（Canvas 贴图 / 精灵），无外部图片素材。

## 五、错误处理与自查

| 检查项 | 处理方式 |
| --- | --- |
| 断网 / CDN 失败 | 各页加载后检测 jQuery / Bootstrap / ECharts 是否挂载，未挂载显示红色提示条；三维页另有资源错误捕获与 8 秒超时兜底 |
| 空数据 | `data.json` 为空集合时，首页、查询页、统计页各区块均显示“暂无数据”虚线占位，图表不初始化、不报错 |
| file:// 直开 | fetch 被拦截时自动回退内置数据，Console 仅 warn，无红色报错 |
| 375px 手机 | 导航折叠为汉堡按钮、选项卡可横滑、卡片单列、图表降为 300px、三维 HUD 收起说明文字，无横向滚动条 |
| 768px 平板 | 卡片两列、统计表格 `table-responsive` 横向滚动 |
| 1200px+ 桌面 | 卡片三列、图表左右分栏、三维场景全屏俯瞰 |

建议在 Chrome 与 Edge 各打开一次，F12 Console 无红色报错；截图时按作业要求截全屏或用手机直接拍摄屏幕。
